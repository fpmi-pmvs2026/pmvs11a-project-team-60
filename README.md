# PmvsLabTracker

**Учебный Android-проект — трекер лабораторных работ ПМиВС (stanulpych)**

## Description

PmvsLabTracker — мобильное приложение для студентов направления «Программирование мобильных и встраиваемых систем».  
Оно помогает вести список лабораторных модулей (ЛР №5–№10), отмечать статус выполнения, хранить ссылки на репозитории и заметки, а также получать напоминания о дедлайнах.  
Данные хранятся локально в Room; синхронизация с облаком не обязательна — приложение ориентировано на офлайн-контроль прогресса.  
Реализация: Kotlin, Jetpack Compose, MVVM, Hilt, WorkManager, DataStore.

## Installation

1. Клонируйте репозиторий (при использовании сабмодуля с кодом):

```bash
git clone --recurse-submodules <URL_ЭТОГО_РЕПОЗИТОРИЯ>
cd pmvs-labtracker-project_stanulpych
```

2. Инициализация сабмодуля (если клонировали без `--recurse-submodules`):

```bash
git submodule update --init --recursive
```

3. Требования:
   - Android Studio (последняя стабильная);
   - JDK 17;
   - Android SDK (`compileSdk = 34`, `minSdk = 26`, `targetSdk = 34`).

4. Откройте каталог `code/` в Android Studio, выполните Gradle Sync и запустите конфигурацию `app`.

**Быстрый запуск на эмуляторе:**

```bash
./scripts/run-android.sh
```

## Usage

- На экране **«Мои лабораторные»** добавьте модуль (номер ЛР, название, ссылка на git).
- Отмечайте статус: `запланировано` → `в работе` → `сдано`.
- Откройте репозиторий лабы в браузере одним нажатием.
- В **«Напоминания»** задайте дату защиты — WorkManager покажет уведомление.
- В **«Настройки»** выберите семестр по умолчанию и тему оформления.

Сборка из `code/`:

```bash
./gradlew assembleDebug
./gradlew test
./gradlew connectedAndroidTest
```
