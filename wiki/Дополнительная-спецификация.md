# Дополнительная спецификация

## Нефункциональные требования (сводка)

| Категория | Требование |
|-----------|------------|
| Безопасность | Нет секретов в git; HTTPS для внешних ссылок |
| Надёжность | Room + WorkManager |
| Производительность | IO на фоновых диспетчерах |
| UX | Material 3, тёмная тема |

## Ограничения

- Не интегрируется с Moodle/электронным журналом в учебной версии.
- Один пользователь на устройстве (без аккаунтов).
