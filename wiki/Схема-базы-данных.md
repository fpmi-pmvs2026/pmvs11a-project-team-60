# Схема базы данных

SQL: [schema.sql](../docs/db/schema.sql)

## ER-диаграмма (логическая)

```mermaid
erDiagram
    semesters ||--o{ lab_entries : contains
    lab_entries ||--o| reminders : has

    semesters {
        int id PK
        string title
        int year
    }
    lab_entries {
        int id PK
        int semester_id FK
        int lab_number
        string status
        string repo_url
    }
    reminders {
        int lab_id PK
        int fire_at_epoch
    }
```

## Отличия от типового «новостного» проекта

- Вместо `subscriptions` / `articles` — **семестры** и **лабораторные**.
- Нет составного ключа по URL статьи — уникальность `(semester_id, lab_number)`.
