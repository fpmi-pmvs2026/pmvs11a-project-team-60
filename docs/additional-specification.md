# Дополнительная спецификация

## Ограничения

- Приложение не заменяет электронный журнал кафедры — это личный органайзер студента.
- Ссылки на репозитории не проверяются автоматически без сети.
- Минимальная версия Android: API 26.
- Экспорт отчёта доступен только в текстовом формате (без PDF).

## Требования к безопасности

- Секреты (токены, если появятся) не коммитятся в git.
- Внешние ссылки открываются только через `ACTION_VIEW` (браузер пользователя).
- Уведомления на Android 13+ — после явного разрешения `POST_NOTIFICATIONS`.
- Локальная БД не шифруется (учебный проект); для production рекомендуется SQLCipher.

## Требования к надёжности

- Room обеспечивает доступ к списку лабораторных без сети.
- WorkManager переживает перезагрузку устройства.
- Повторное добавление той же пары (номер ЛР + семестр) блокируется уникальным индексом.
- При удалении трека семестра связанные лабораторные архивируются, а не теряются без подтверждения.

## Требования к производительности

- Списки на `LazyColumn` с ключами стабильных id.
- Тяжёлые операции (экспорт, пересчёт статистики) — в `Dispatchers.IO`.
- Изображения не используются; UI лёгкий для слабых устройств.

## Масштабируемость и сопровождение

- Слои `ui / domain / data` изолируют изменения.
- Use case инкапсулируют правила смены статуса.
- Hilt упрощает подмену репозитория в тестах.
