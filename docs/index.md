# Главная страница

Документация проекта **PmvsLabTracker** (GitHub Pages / docs).

## Краткое описание задачи

Разработать Android-приложение — персональный трекер лабораторных работ по дисциплине ПМиВС:

- добавлять и группировать лабораторные модули;
- отслеживать статус и дедлайн;
- хранить ссылки на git-репозитории и заметки;
- получать локальные напоминания;
- работать без постоянного интернета (кэш Room).
