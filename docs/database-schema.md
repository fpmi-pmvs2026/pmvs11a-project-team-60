# Схема базы данных

Локальная база Room (SQLite) приложения PmvsLabTracker.

## SQL-файл

- [schema.sql](db/schema.sql)

## Краткое описание

| Таблица | Назначение |
|---------|------------|
| `semesters` | Учебные периоды (название, год). |
| `lab_entries` | Лабораторные: номер, заголовок, статус, URL, заметка, дедлайн. |
| `reminders` | Запланированные напоминания (1:1 с `lab_entries`). |

Связи:

- `semesters (1) → (N) lab_entries`
- `lab_entries (1) → (0..1) reminders`
- при удалении семестра лабораторные **не** удаляются каскадно — переносятся в «без семестра» (мягкая политика).
